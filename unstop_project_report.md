# EdityourPDF

## 🚀 Project Description
**EdityourPDF** is a comprehensive, AI-powered web application designed to handle a vast array of PDF and image manipulation tasks directly within the browser. Emphasizing privacy, speed, and a seamless user experience, it eliminates the need to upload sensitive documents to third-party servers. With a modern, intuitive "Glassmorphism" interface, it serves as a one-stop-shop for document management, bringing professional-grade editing tools and AI capabilities into a single, accessible platform.

## 💡 The Problem it Solves
Users frequently struggle with managing, editing, and securing PDF and image files, often relying on multiple paid software solutions or risky online tools that compromise data privacy by requiring server uploads. **EdityourPDF** solves this by executing complex file processing entirely on the client side. This ensures absolute data privacy, zero upload wait times, and a frictionless, cost-free experience for the user.

## ✨ Key Features
### 📄 Comprehensive PDF Tools
* **Core Editing:** Edit, Merge, Split, Compress, Crop, Reorder, and Rotate PDFs effortlessly.
* **Format Conversion:** Convert between PDF and Word, Excel, PowerPoint, Text, Markdown, and various Image formats.
* **Security & Privacy:** Password protect, unlock, and redact sensitive information. All processing is 100% client-side, guaranteeing that your data never leaves your device.
* **Advanced Utilities:** Add custom watermarks, insert page numbers, fill and flatten forms, compare PDFs side-by-side, and manage metadata.

### 🖼️ Advanced Image Editor
* **Image Manipulation:** Resize, compress, crop, enhance (adjust brightness, contrast, sharpness, etc.), and rotate images.
* **Conversion & Watermarking:** Convert between JPG, PNG, WebP, and BMP. Add custom text watermarks.
* **AI Image Generation:** Generate stunning AI art directly from text prompts.

### 🧠 AI & Smart Capabilities
* **AI Document Summarization:** Built-in AI Summarization (powered by Google Gemini) to quickly extract key insights, bullet points, or Q&As from any PDF.
* **Optical Character Recognition (OCR):** Extract searchable text from scanned documents and images using advanced client-side OCR.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Custom Glassmorphism UI, Responsive Design), Vanilla JavaScript.
* **Document Processing Libraries:** PDF-lib (with Cantoo fork for Encryption), PDF.js, JSZip, PPTXGenJS, Docx.js.
* **AI & OCR:** Google Gemini API (for summarization), Tesseract.js (for client-side OCR).
* **Other Tools:** Marked.js (Markdown parsing), FontAwesome.

## 📈 Impact
**EdityourPDF** empowers students, professionals, and everyday users to take complete control of their digital documents without recurring subscription costs or privacy concerns. By democratizing access to premium PDF and image tools through a lightning-fast, secure, and beautiful web interface, it sets a new standard for online productivity tools.
